# Security Policy

## Supported Versions

Versi yang saat ini didukung dengan update keamanan:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Laporkan kerentanan lewat **Private vulnerability reporting** GitHub
(repo → Security → Report a vulnerability). Jangan buka issue publik
untuk kerentanan yang belum ditambal.

Yang bisa diharapkan:

- Konfirmasi penerimaan laporan maksimal 3 hari kerja.
- Update progres tiap 7 hari sampai status final.
- Jika diterima: patch + rilis minor + kredit reporter (jika bersedia).
- Jika ditolak: alasan tertulis; laporan tetap rahasia.
